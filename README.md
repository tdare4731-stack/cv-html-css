# Projet CV HTML & CSS

Création d'un CV personnel responsive en HTML et CSS, réalisé dans le cadre d'un exercice de développement web.

## Fonctionnalités
- Design responsive respectant les consignes de mise en page.
- Utilisation d'un conteneur principal de 1160px.
- Structure respectant un workflow Git rigoureux (branches de fonctionnalités et Pull Requests).
